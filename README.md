# AI Tutor

> 🚧 Ранняя пилотная стадия — контент и структура ещё меняются, обратная связь собирается вручную с ограниченного круга тестеров.

Agent-driven онбординг в управление AI-агентом: агент в терминале сам, шаг за шагом и объясняя «зачем» на каждом шаге, разворачивает вокруг реального (в пилоте — учебного) проекта пользователя рабочий процесс — локальную wiki против потери контекста между сессиями и Kanban-доску против хаоса задач, — подстраивая глубину объяснений под то, что пользователь уже знает. Не курс с лекциями и не мастер установки агента — методология, которую пользователь осваивает на своём собственном проекте.

## Как попробовать

Открой терминал с AI-агентом (например [opencode](https://opencode.ai)) в пустой папке будущего учебного проекта и напиши первым сообщением:

    Прочитай https://tutor.diworld.pro/Tutor.server.md и делай, что там сказано

Дальше просто отвечай агенту как обычному собеседнику — дальше он ведёт сам, шаг за шагом.

## Содержимое репозитория

- `lite-template/` — шаблон проекта (локальная wiki + Kanban-доска + протокол работы), который онбординг-агент устанавливает в проект пользователя пошагово, объясняя каждую часть по ходу установки.

Pro-версия (более глубокое, адаптивное сопровождение через сервер) появится в этом же репозитории позже.
